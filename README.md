# Text-scrubbing-tool

Berkeley Cleaner

A small offline tool that formats client information before data entry. Paste a full address into the Street field, and it fills in the city, province and postal code and cleans each field.

Features

Removes accents, hyphens, apostrophes and other special characters
Converts ALL CAPS text to proper case
Splits the unit from the street address (e.g.210-88 Elm St. becomes line 1 88 Elm St. and line 2 210)
Splits a full name into first and last name, each with its own copy button
Checks that the postal code matches the province

Privacy
It is one HTML file that runs entirely in the browser. It makes no network requests and stores no data, so nothing is saved when the tab is closed.

Usage
Download berkeley-cleaner.html and open it in a browser. Use synthetic data when testing.
